## Theory and Volta implications

Chat templates and instructions determine how native roles and tool syntax reach the model. Correct model-specific formatting precedes speed comparison.

On SM70, require an actually dispatched compatible kernel and include conversion, workspace, launch and verification costs. The 16 GB budget includes weights, attention KV, recurrent states, graph pools and transient allocations. Quality, end-to-end latency and energy per successful task take precedence over a token-throughput screen.

R406 tested a distinct fresh BFCL-v4 native-tool instruction treatment. The candidate emitted a valid native call on irrelevance_68; the strict no-call quality gate failed, so the screen stopped after 51 paired tasks. No full-suite score, performance result, or Champion claim; M07 remains PARTIAL. Static implementation review (no GPU): at llama.cpp commit 097cf33, schema-constrained response_format selects the response parser before native tool parsing, while custom grammar with tools is rejected. The exact R406 engine build is not available among installed candidate binaries; no GPU variant admitted.
