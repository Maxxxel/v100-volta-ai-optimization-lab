## Theory and Volta implications

Quantizing attention values reduces KV storage but changes the attention value product. Its error behavior differs from key quantization.

On SM70, require an actually dispatched compatible kernel and include conversion, workspace, launch and verification costs. The 16 GB budget includes weights, attention KV, recurrent states, graph pools and transient allocations. Quality, end-to-end latency and energy per successful task take precedence over a token-throughput screen.

## Decision and remaining research

F16/Q8/Q4-Value sowie32K-Q8/Rotation aus vorhanden;Q4 verliert Format, Q8/Rotation zeigt keinen praktischen Gesamtgewinn.

**Remaining scope:** Kein weiterer Q8-Value32K-Kontrolllauf. Key/Value-Kombination nicht priorisieren; adaptive Draft-Machbarkeit als eigener Faktor prüfen.

**Reopening condition:** Neuen Value-Cachepfad nur bei konkret anderem kompatiblem Layout/Qualitätsvertrag; kein weiterer32K-Q8-Kontrolllauf.

**Next action:** New value layout/precision needs an implemented compatible kernel and independent functional/semantic oracle. No further unchanged32KQ8 run or blind parameter sweep.

These canonical rationale excerpts preserve the original language. Potential combinations require independently qualified constituents and fresh interaction controls. Transfer to another model requires compatible architecture, weights, tokenizer, state layout and engine dispatch.
