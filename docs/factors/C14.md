## Theory and Volta implications

Computation and output accumulation precision affect rounding and bandwidth. Coupled precision/output changes are not a pure isolated accumulation experiment.

On SM70, require an actually dispatched compatible kernel and include conversion, workspace, launch and verification costs. The 16 GB budget includes weights, attention KV, recurrent states, graph pools and transient allocations. Quality, end-to-end latency and energy per successful task take precedence over a token-throughput screen.

## Decision and remaining research

R390: isolated FP32 weighted-V multiply-accumulate/rescaling on SM70 F16 D256/GQA4, single-query long-KV tile path. Same seeded native binary and 86 identical tensor-upload SHA records per arm. A and B each pass 4/6 native CPU-reference cases at unchanged NMSE<=5e-4. Both 32K errors remain above the bound; error reductions are only 1.1513% and 1.1937%, below the preregistered 50%. Actual candidate dispatch verified. TESTED_NEGATIVE for this corrective precision variant; no model admission, task-quality, inference-speed or energy-per-success result. Original C14 PARTIAL scope and all Champions retained; no diagnosis of an isolated root cause.

**Remaining scope:** Other precision implementations are not universally exhausted. The isolated weighted-V FP32 correction failed its fixed native gate; no parameter sweep or model test justified by this result.

**Reopening condition:** Neue Präzision benötigt tatsächlichen anderen Akkumulationspfad und sinnvolle Toleranzen; Numerik-/Qualitätsgrenzen behalten, keine bloße Formatumbenennung.

**Next action:** Preserve the scoped negative and stop this precision branch. Reopen only for a distinct source-backed implementation with a practical hypothesis, independent inputs and unchanged correctness bounds.

These canonical rationale excerpts preserve the original language. Potential combinations require independently qualified constituents and fresh interaction controls. Transfer to another model requires compatible architecture, weights, tokenizer, state layout and engine dispatch.
