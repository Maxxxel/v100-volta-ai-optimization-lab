## Measured optimization decisions

**LOCAL MEASURED / LOKAL GEMESSEN**, within each linked scope:

- **Tool MTP:** fresh matched full-category control retains 178/200 on both arms; response wall falls 38.66%, conservative GPU J/success 41.10%. This is confirmation of existing measurements, not another independent leaderboard score. [R546](experiments/R546.md)
- **Qwen27 integrated MTP:** fresh development control retains 16/16 coding and 13/16 mock tools in both arms, with 35.43% lower response wall and 37.94% conservative GPU J/success reduction, at +1146 MiB peak VRAM. Exposed development data, not a new official score, lossless-token proof or population noninferiority. [R551](experiments/R551.md)
- **Historical HBM07:** fixed 2K/4K prefill token-event TTFT medians improve 8.55% / 8.81% against the matched stored A0. Higher VRAM and the exact historical engine/workload limits remain; no universal decode gain. [R90](experiments/R90.md)
- **Historical prefix and energy/context profiles:** retain prefix reuse only for reused-prefix workloads, the independently qualified 32K profile, and the 175-W low-VRAM natural-SSE profile in their own scopes. They are not automatically transferable to current native-chat/MTP captures. [R80](experiments/R80.md) · [R221](experiments/R221.md) · [R113](experiments/R113.md)
- **Negative evidence retained:** Omni MTP coding 131/164 versus 134/164 and Agent33 loss; Gemma Q8-key coding 151/164 versus 156/164; Gemma Thinking development tool regression and much higher costs. No synthetic-speed exception overrides these quality gates. [R541](experiments/R541.md) · [R543](experiments/R543.md) · [R544](experiments/R544.md) · [R545](experiments/R545.md)

These gains are not added together. Existing scoped reference/Champion profiles remain in the [reference archive](configurations.md); no new combination or universal Champion is inferred here.

- **Agent safety versus format:** Gemma Agent33 has 4 policy-violation cases and 32 rejected tool-call events, with 1 case failing the final-output contract. Repeated blocked calls are not independent failed cases or production writes. [Separate per-profile policy, parser, contract and semantic counts](configurations.md) retain the original replay and scores; zero recorded parser failures is not proof of valid arguments or safe decisions. [R534](experiments/R534.md)
- **External evidence / EXTERN BELEGT:** published model cards, papers, source implementations and community measurements remain [source evidence](benchmark-register.md), never local score replacements or proof of a speedup cause.
- **Unverified / NICHT VERIFIZIERT:** unattended production stability; global model superiority; automatic multi-model routing/switch costs; a heavier multi-agent harness; independently rebuilt binary equivalence; and exact public reproduction of private Agent33 inputs. R537 has only five paired role cases. [R537](experiments/R537.md)
- Model-specific native templates, context/output, sampler, quantization, engine and harness settings remain part of every result. The shared HumanEval/32 canonical-reference anomaly is retained and disclosed; all 164 official tasks remain. These are declared local protocols, not publisher-protocol reproductions.
- GPU counter energy covers declared request groups, including failures, not CPU/system energy. Counter brackets reflect query timing, not calibration confidence. Server generation timing is not TTFT; unavailable TTFT, prefill/decode or hardware values are not extrapolated.
- R538 remains 167/199 PARTIAL at its original task limit. Historical budget conditions and old audits remain unchanged. No qualification is inferred from a build, CPU test, source release or experiment number.
