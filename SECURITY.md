# Security and confidential information

Never post a secret or private infrastructure detail in a public issue. Use
GitHub private vulnerability reporting if enabled; otherwise contact the maintainer
through an established private channel. Do not attach logs or model memory dumps.

The publication schema excludes prompts, model outputs, credentials, network
configuration, private tool entities and weights. Automated scanning supplements
an explicit allowlist; it cannot prove arbitrary free-form prose is harmless.
Review canonical rationale fields before adding new export fields.

If sensitive material is discovered, stop subsequent publishing, revoke affected
credentials, and coordinate remediation. Scientific negative results must remain
visible unless removal is necessary for confidentiality or legal obligations.
